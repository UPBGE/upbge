Game UI Guide

How the Complete UI Example is made: an inventory with equipment and crafting, a chest, settings, a pause menu and a HUD. Open the finished game with Add › Game UI › Open Complete UI Example. Add a part to your game with Add › Game UI › Templates. A chapter's badge names its template.

How UPBGE object UI works

  • A menu is a collection. The example keeps them all in the UI collection. Keep every piece a child of its panel, so it moves with it.
  • Build with the UI collection visible. Turn on its Disable in Viewports at the end (chapter 12).
  • A grid copies its first cell with the cell's children. The first mesh child (not the glow) shows each item's icon. The first text child shows its count.
  • Open Object Menu shows a menu through a camera of its own (InvCamera). The menu's tree sits on its panel and runs only while the menu is open.
  • A UI Element is any object with Game Components tab › UI Element on. It takes clicks, focus and drags.
  • On UI Event reports what happens to an element, with the element's Action name.
  • A tree runs on the object it is applied to. Open the tree in the Logic Node Editor, select the object, then Game Components tab › Logic Nodes › Apply To Selected.
  • Widgets (Slider, Toggle, Selector, Text Field, Bar) change or show a game property by themselves.
  • Live text: braces in a text's body show values and keys: {Player.walk_speed:2}, {player_name} (its own, else the nearest parent's), {Move}, {Grab:Gamepad}.

Reading the tables

  • Location of a child is its offset from the parent. Parent it with Ctrl P › Object (Without Inverse), then type the Location. Other objects use world positions.
  • Shape: Add › Mesh › Plane or Cube, sized in Edit Mode so the object's Scale stays 1. An upright plane is a plane turned 90° on X in Edit Mode. A text's Size is in the Data tab › Font › Transform, its Horizontal and Vertical in Paragraph › Alignment.
  • Mesh middle: where the mesh sits from the origin, when not at it. Move the mesh by it in Edit Mode.
  • Settings lists only what differs from a new object or node. What most objects share is said once above the table.
  • UI, Drag, Look, Widget, Nav, Adv: Game Components tab › UI Element and its sub-panels Drag and Drop, Look, Widget, Navigation, Advanced.
  • Numbers in circles match the screenshot above the table.
  • A chapter's badge names its template. A menu's template adds the whole chapter for your player: objects, logic, actions and properties. Walking and Pickups add less; their chapters say what.

5. Menu sounds Template: Add › Game UI › Templates › UI Sounds

A short tone when the highlight moves, on a click, when Back closes a menu, and when a press does nothing.

The UI Sounds template adds this frame and the example's tones. A menu template adds it too while your scene plays no menu sounds.

The tones are packed in the example. Append them (File › Append › game_ui_example.blend, next to this page › Sound) or use your own.

Try it: open the inventory and point at the cells: each move ticks. Click a cell, and close the inventory with Esc.

12. Finish

  1. Turn on Disable in Viewports for the UI collection. It is the screen icon in the Outliner; show it with Outliner › Filter › Restriction Toggles.
  2. The menus then get out of the way in the 3D view. The library's items stay out of the game world.
  3. Never exclude the UI collection: the game needs it.
  4. Play and try every chapter's “Try it” with the mouse, the keyboard and a gamepad.

Common mistakes

  • Icon in the wrong color: Emission Color must match Base Color.
  • Items not picked up: a pickup needs an item property. On Collision looks for it.
  • An item with no icon or name: its item must name an Item Library object.
  • One cell, or cells in the wrong place: the Slot Template is the first cell. Rows above 0 make the copies, Spacing apart.
  • A piece left behind when the panel moves: make it a child of the panel.
  • A menu never shows: the UI collection must not be excluded. Open Object Menu needs its Camera and Collection.
  • A text does not update: braces go in the text's body.
  • Esc no longer quits: an action you added on Esc takes it. Add a Quit button.
  • The pause key does not close the menu: link the Input Action straight into Open Object Menu, and nothing out of it.
  • Clicks go through to the game: the panel needs UI Element on (Pointer stays Block).
  • Two menus' logic in one tree: keep one tree per menu, on its panel.
